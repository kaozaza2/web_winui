WinUI 3 design for the Odoo backend

Microsoft's Fluent Design System, applied to the whole web client — without changing a single Odoo template.

Every module follows

Odoo modules build their interface out of a shared vocabulary of o_* and Bootstrap classes. web_winui re-defines the SCSS variables those classes compile from, so form, list and kanban views — in core apps and in third-party ones alike — adopt the Fluent look with no per-module work.

Built from the WinUI sources

The colour ramps, corner radii, type ramp and control metrics are transcribed from the WinUI 3 resource dictionaries — including the details that make Fluent recognisable: the asymmetric control stroke that is darker along its bottom edge, the accent underline a focused TextBox grows, and the 3px selection pill.

Light, dark and your accent colour

Pick light, dark, or follow the operating system. Choose an accent from the Windows 11 palette or any colour you like — the five derived shades are generated with the same mixing formula Windows uses. Everything applies instantly, with no reload and no asset rebuild.

Mica, Acrylic and density

The window sits on a Mica backdrop with the content in a rounded layer, exactly as a WinUI app does. Flyouts, dialogs, tooltips and notifications are Acrylic. Density switches between the desktop 32px controls, a compact grid for data-heavy screens, and 44px touch targets.

Accessible by construction

The focus rectangle is the Fluent two-tone outline and appears on keyboard focus only. High-contrast mode hands every stroke back to the system colours. Reduced motion is honoured from the operating system and from a per-user switch, and transparency effects can be turned off entirely.
